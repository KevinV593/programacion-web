# Visita Ecuador 🇪🇨

**Visita Ecuador** es un sitio web turístico desarrollado para promocionar los atractivos naturales, culturales y turísticos del Ecuador, destacando sus cuatro regiones: Costa, Sierra, Amazonía y Galápagos.

## Información del proyecto

- **Estudiante:** Kevin Vaca
- **Asignatura:** Programación Web
- **Proyecto:** Parcial 1
- **Tecnologías:** HTML5 y CSS3

## Características

- Presentación turística del Ecuador.
- Exploración de las cuatro regiones del país.
- Sección de destinos turísticos.
- Galería fotográfica.
- Información sobre paquetes turísticos e itinerarios.
- Formulario de contacto con validaciones HTML5.
- Diseño adaptable a dispositivos móviles y de escritorio.
